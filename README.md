# 🌙 Dark Mode Toggle

A simple Dark Mode / Light Mode toggle built using HTML, CSS, and JavaScript.

## 🚀 Features

- Toggle between Light Mode and Dark Mode
- Uses JavaScript Event Listeners
- DOM Manipulation with `querySelector()`
- Dynamic background color switching
- Beginner-friendly project

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📚 Concepts Practiced

- DOM Manipulation
- Event Listeners
- Variables
- Conditional Statements (`if...else`)
- State Management

## 🎯 Learning Outcome

This project helped me understand how JavaScript interacts with the DOM and how to update UI elements dynamically based on user actions.
